# Retained Evidence

- `benchmark-report.json` contains per-document accuracy and aggregate metrics
  generated by the public CLI.
- `VERIFICATION.md` records the clean-environment Python, TypeScript, coverage,
  and benchmark results for this revision.

Regenerate the benchmark:

~~~bash
docintel benchmark samples/benchmark.json \
  --report evidence/benchmark-report.json
~~~

The checked-in data is synthetic and the benchmark is a regression baseline,
not an independent evaluation of arbitrary production documents.
