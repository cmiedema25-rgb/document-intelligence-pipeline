# Changelog

All notable changes to this project are documented here.

## 1.0.1 - 2026-09-05

- Clarified audience in README (ops/finance extract-and-audit use case).

## 1.0.0 - 2026-08-30

- Added deterministic invoice and purchase-order classification.
- Added OCR block and plain-text input adapters.
- Added evidence-linked field and line-item extraction.
- Added confidence scores, normalized dates and currency amounts.
- Added arithmetic validation and evaluation metrics.
- Added a local JSON HTTP API and strict TypeScript SDK.
- Added Python and TypeScript test suites with GitHub Actions CI.
